Prompt n°1 - Composant React ProductCard :

Rôle : Senior Frontend Developer. Contexte : Next.js 15 (App Router), TypeScript, Ecoshop.
Tâche : Il va créer un composant React `ProductCard` qui affiche un produit avec props dont {name:string, price:number, onAdd:()=>void}.
Règles :
- Accessible : bouton avec aria-label, focus visible, contrast WCAG AA
- Style minimal et sobres, pas de lib externe
- Internationalisation (i18n) française
- Typage strict TS
- Fournir un petit exemple d’usage
- Tests unitaires avec @testing-library/react pour vérification bouton et rendu
Délivrables :
- Fichier `ProductCard.tsx` autonome
- Exemple d’intégration dans une page
- Tests Jest associés
